# 多 Agent 协作登记表

在同一仓库并行运行多个 Agent 任务时，**开工前先在此登记，开工后立即更新状态**。规则见 `CONTEXT.md` 的「Multi-Window Agent Collaboration」一节。

## 如何登记

- 追加或更新一行自己的条目即可（改动只限自己的行，不要重排他人行）。
- 文件域写清楚要改的文件/目录；如果与已有条目重叠，先协调换域。
- 完成后把状态改为 `done`，并清理你的行内容或整行删除。
