# ADR-0001：托管代理运行时

- 状态：已接受
- 日期：2026-07-22

## 决策

API Monitor 保持其 Rust Agent 作为唯一的主机控制模块。Agent 管理一个固定的 sing-box 数据面运行时；API Monitor 不实现代理协议，也不复制 Xboard-Node 的实现代码。

一台新服务器仅使用该 Agent 引导（bootstrap）一次。注册完成后，面板复用同一个出站 Agent 连接来处理主机清单、监控、代理内核安装与升级、内部节点生命周期、配置对账、健康检查、流量计数和拆除。sing-box 是由 Agent 管理的可替换数据面进程；它不是额外的管理 Agent，也不需要单独在面板注册。正常生命周期操作不得依赖交互式 SSH。

控制面刻意拆分为独立、分层的生命周期：

1. 实例管理：安装、升级、验证或移除固定的 sing-box 运行时。它不创建面向订阅者的节点。
2. 节点管理：只针对运行时已就绪的实例，然后创建协议凭据、分配端口、写入每节点配置，并对相应的 systemd 单元做对账。
3. Cloudflare Tunnel：托管节点的可选访问路径。它拥有 cloudflared、Named Tunnel、DNS 记录和 ingress 路由；它不是第二个代理运行时。

每个编排操作都是异步的，并暴露可重放的阶段进度。操作完成后重连仍必须能返回最终结果。

面板保存期望状态。Agent 校验带版本的候选配置，原子化应用，验证运行时健康状态，失败时回滚。当面板或 Agent 不可用时，代理数据面继续运行。

订阅者访问从计划图（plan graph）对账而来，绝不从订阅记录中复制的节点列表得来。每个订阅有一个公开的下载 token，外加独立的 VLESS UUID 和 Hysteria2 密码凭据。Agent 使用订阅 ID 作为 sing-box 用户名，并且只在 loopback 的 V2Ray Stats gRPC 监听器上暴露统计信息。它在本机持久化计数器基线，并发送以 `(boot_id, sequence)` 为键的增量；Go 账本规范化凭据别名、在计划配额处钳制最终增量，并在计划变化、被禁用或达到上限时排队节点对账。对已删除订阅或节点的过期报告会被确认并忽略，以免存储转发式采集阻塞后续报告。

计划拥有配额和重置策略。订阅选择计划，不携带第二个独立的过期时间或配额。月度周期切换被持久化，并排队一次在重置后恢复用户的对账。队列代数（generation）是单调递增的，因此节点应用期间到达的变更不会丢失。

节点流量术语是明确的：

- `ownership`（归属）：`self`（自有）或 `external`（外部）
- `management`（管理）：`agent`（托管）或 `unmanaged`（非托管）
- `traffic_reporting`（流量上报）：`trusted`（可信）或 `unavailable`（不可用）

导入的外部节点默认是 external、unmanaged、unavailable。它们的流量绝不能计入物理主机或自建代理流量。

## 生产支持矩阵

托管运行时支持 amd64 或 arm64 的 systemd Linux。刻意不做发行版和发布版本白名单：Agent 验证其实际依赖的能力（systemd、架构、运行时二进制校验、可写的状态目录、可绑定的端口和受支持的火墙适配器），而不是拒绝其他本可兼容的主机。

## 安全与交付

- 每台机器拥有独立的 256 位凭据。
- 现有全局密钥安装会在首次成功认证时迁移。
- Linux 发布二进制是 musl 构建，安装时校验 SHA-256。
- 运行时配置是私有的（`0700` 目录、`0600` 文件）。
- 代理生命周期任务使用结构化任务类型，不使用 shell 文本。

## 托管节点端口策略

自建节点绝不假设 TCP/UDP 443 可用。面板从闭区间 `45654-55654` 分配端口，并把所选端口作为托管节点不可变部署身份的一部分存储。

- 分配以服务器为作用域，排除该服务器上已分配给其他托管节点的每个端口。
- Agent 必须在应用配置前执行本地 TCP 或 UDP 绑定预检。发生冲突时，扫描配置区间，把所选端口原子写入生效的核心配置，应用后向面板报告最终端口。它绝不能替换或停止占用进程。
- VLESS REALITY 使用 TCP，Hysteria2 使用 UDP。但分配器在两个传输协议上仍保持每台服务器数字端口唯一，以简化防火墙规则、诊断和订阅输出。
- Agent 只通过受支持的主机防火墙适配器打开所选协议和端口。它绝不会整体替换主机防火墙策略。
- 订阅链接和 Mihomo/sing-box 输出使用实际分配的端口；任何渲染器都不得静默替换为 443。
- 导入的外部节点保留其提供的端口，不受此策略影响。
